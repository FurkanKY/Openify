Changelog

Every Openify release, newest first, with what was added, changed and fixed. Installers and checksums for each version are on the GitHub releases page.

0.1.2

13 November 2026. A light theme, a native ARM64 build for Windows, and smoother motion.

Added

  • A light theme with warm off-white surfaces, cover accents that stay readable, and softer shadows. Settings offers Dark (still the default), Light and System. System follows the Windows app mode right away, including the window title bar.
  • A native Windows on ARM installer, Openify-win-arm64-Setup.exe, with its own update channel.
  • winget manifests, plus a script that fills in their hashes from a release.
  • Optional Discord Rich Presence showing song, artist, cover and progress. It stays hidden until a Discord application ID is set at build time.
  • OPENIFY_TEST_THEME=light|dark, for isolated visual test runs.

Changed

  • Cover colours now blend in a perceptual colour space, so transitions no longer turn muddy halfway. The current lyric line fades in instead of jumping, and switching between lines slides.
  • Settings and Tools centre their column in wide windows instead of leaving most of the page empty on the right.

Fixed

  • Searching while Spotify is unreachable no longer leaves a loading skeleton on screen forever. After 10 seconds the page says Spotify could not be reached.

0.1.1

13 November 2026. A redesigned search, a wider seek bar, and language and time zone fixes.

Changed

  • Search was redesigned. The search box in the title bar is wider and takes its tint from the cover that is playing. Before you type, it shows your recent searches, things to listen to again and genre shortcuts.
  • Results are grouped into a top result, songs, artists, and albums and playlists. You can move through them with the arrow keys. Commands only appear when your search clearly matches one.
  • The progress bar in the floating player has its own row and is much wider, which makes seeking easier. Lists now end above the floating player, with a soft fade behind it.

Fixed

  • Home, Explore and similar-artist requests now use the interface language (English or Turkish) instead of always asking Spotify for Turkish content. The Explore page cache is kept separately for each language.
  • Home now uses your computer's time zone instead of always assuming Europe/Istanbul.

Other

  • The documentation was corrected and updated: measured memory figures, privacy notes about play reporting and Spotify Connect, and the known limitations.
  • Release builds are now made by GitHub Actions and published with SHA-256 checksums in SHA256SUMS.txt.

0.1.0

12 November 2026. The first public release.

Added

  • A native Windows Spotify client for Premium accounts, written in Rust: a gpui interface, librespot playback and a local SQLite cache.
  • Sign-in through the browser. The session is kept in the Windows Credential Manager.
  • Home, Explore, Library, artist, album and search pages, with library folders, pins and sorting.
  • A command palette (Ctrl+K), keyboard shortcuts, media keys, a tray icon, the Windows media overlay and an optional global search hotkey.
  • Gapless playback, optional crossfade, volume normalization, quality up to 320 kbps, and recovery after the output device changes.
  • A 10-band equalizer with presets and a preamp, and headphone profile search backed by the OPRA database.
  • Library tools: a duplicate and version finder, merging and splitting playlists, permanent sorting, JSON backup and local listening statistics. Library edits can be undone, and edits made offline are queued.
  • Synced lyrics in a side panel and full screen, with LRCLIB as a fallback and an optional translation line.
  • Smarter shuffle and queue rules (one version per song, skip explicit, never play an artist, hide songs), radio from a song, artist, album or playlist, and a private session.
  • A Spotify Connect device. It is on by default and can be turned off in Settings.
  • Track credits, similar artists and artist following.
  • A friend activity panel. It is off by default and experimental.
  • English and Turkish interface.
  • An installer with automatic updates, a portable zip, and a rollback when a new version fails to start twice.

Known limitations

  • Screen readers are not supported yet.
  • Dark theme only, and Windows only. (The light theme arrived in 0.1.2.)
  • Plays made in Openify are not reported to Spotify.
  • Friend activity and artist following have had only limited testing against a live account.
