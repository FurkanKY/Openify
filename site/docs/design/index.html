Design system

Openify combines neutral surfaces, cover-derived color and a floating player. Shared tokens keep pages and controls consistent across Dark and Light themes.

Visual structure

Large Figtree titles establish hierarchy; covers provide the accent and ambient glow. The library shelf, headers and rows align through page_margin. It ranges from 32 to 64 px with content width, interpolating near the 1280 and 1600 px thresholds.

Interactive components have five states: normal, hover, pressed, keyboard focus and disabled. Tonal layers distinguish states; shadows mark floating surfaces.

Secondary text uses foreground opacity: 72% in Dark and 80% in Light; labels use 68% and 78%. Disabled icons use 28%. Tests check readable text and surface combinations against the 4.5:1 contrast target.

Settings offers Dark, Light and System. Missing or unknown settings default to Dark; System follows Windows app mode.

Cover-derived color

The accent colors playing rows, level bars, primary buttons, focus rings and selected shelf cards. ensure_contrast lightens or darkens it against the target background. The 460 px glow blends cover color with the background: Dark caps its luminance, while Light uses a restrained tint. Cover changes transition over 800 ms.

Typography

Embedded Figtree (OFL) is used for titles at 18 px and above. Smaller text uses Segoe UI Variable Text. The six roles pair font size with line height; weights depend on the component.

Spacing, shape and depth

Spacing follows 2, 4, 8, 12, 16, 24, 32, 48 and 64 px. The 2 px step is reserved for closely related lines and compact lists.

Corner radii run from 2 px for bars through 4 px covers, 6 px rows, 8 px shelf covers, 12 px floating panels and 20 px search surfaces. Icon buttons are circular; primary buttons, chips, title-bar search and the player use pill shapes.

State layers use white in Dark and dark foreground in Light: hover 6%, selected 10%, pressed 14%. Playing rows use cover tint at 8%, 12%, 16% and 20%. Floating surfaces and slider handles have shadows; docked panels use a quieter shadow.

Motion tokens set hover and press to 140 ms, entrances to 220 ms, exits to 160 ms and cover transitions to 800 ms. Reduce animations makes these durations zero.

Named rules

One Light
Use the cover accent, with the default orange when no cover is available.
Night Stays
Cap the dark theme's glow so labels retain contrast.
Tonal Layer
Reuse the same state opacities across components.
Six Sizes
Get font size and line height from type_role.
Steady Digits
Use tabular digits for changing times, positions and counters.
Floating Shadow
Keep ordinary cards, rows and bars shadow-free.
Single Color Logo
The notched O ring and light dot use foreground or night, independently of the cover accent.

Component checklist

  • Use theme.rs spacing, radii and type roles; align blocks with page_margin.
  • Add new components to OPENIFY_GALLERY=1 with all five states.
  • Pass cover accents through ensure_contrast and use translucent foreground for secondary text.
  • Keep category information in the metadata line; omit uppercase labels above titles.
  • Keep Figtree at 18 px or larger and reserve shadows for the defined surfaces.

How the rules are checked

src/ui/design_rules.rs scans listed UI files for raw spacing, radius, font size, shadow and color values. It checks icon-button tooltips and selected focus-order rules. Theme tests cover contrast and glow brightness; layout tests check visible song rows at small window sizes. See architecture tests.
