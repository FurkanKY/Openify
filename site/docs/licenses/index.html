Licenses

Openify is free software under the GPL-3.0-or-later. This page explains what that means in practice, and lists the licenses of the fonts, icons, data and Rust crates that come with or are used by the app.

Openify's own license

Openify is licensed under the GNU General Public License, version 3 or (at your option) any later version. In Cargo.toml that is the SPDX expression GPL-3.0-or-later, and the full text is in the LICENSE file in the repository.

This page is a plain-language summary, not legal advice. If a decision depends on the exact wording, read the license text itself.

What it means if you just use Openify

  • You can install and run it for any purpose, on as many computers as you like, at no cost.
  • You can read the source code, study how it works and change it for your own use.
  • You can share the app with others, with or without changes, as long as the terms below are followed.
  • There is no warranty. The GPL says the software is provided as is, and that applies here too.

The license covers Openify's code. It says nothing about Spotify's service or its terms, which are separate. See the Spotify disclaimer below.

What it means if you fork or redistribute it

You are free to fork Openify, change it and publish your version, including under a different name. The GPL attaches a few conditions to that freedom:

  • If you distribute a modified version, or a build of one, you must make the corresponding source code available to the people who receive it, under the same GPL terms.
  • You must keep the existing copyright and license notices, and mark that you changed the files.
  • You cannot add restrictions on top of the GPL. A closed-source, proprietary fork that you distribute is not allowed.
  • Because the license says "or any later version", you may choose to follow a later version of the GPL if the Free Software Foundation publishes one.

If you only change Openify for yourself and never hand it to anyone else, you do not have to publish anything. Contributions sent to the project are accepted under the same license; the contributing guide says so too.

Dependencies matter here. A new crate has to be compatible with GPL-3.0, and the contributing guide asks for a check with cargo deny check licenses.

OPRA headphone data

The headphone equalizer profiles come from OPRA, an open registry started by Roon Labs and kept up by community contributors. Its manufacturer, product and EQ data is licensed CC BY-SA 4.0. The OPRA repository's own code is MIT.

Openify does not ship this data. The database file is downloaded to the cache folder the first time you search for a headphone profile, and refreshed from there. Each profile you select is credited to its creator in the equalizer settings. Openify fits the profile to its own 10-band equalizer, so the bands you get are an adaptation of the original curve. The notice is in assets/licenses/OPRA-NOTICE.txt.

Most entries are permissive: MIT, Apache-2.0, or a choice between them. Spotify disclaimer

Openify is an independent project. It is not affiliated with, endorsed by or sponsored by Spotify AB. "Spotify" and the Spotify logo are trademarks of Spotify AB, and they are used here only to say what Openify works with.

Openify talks to Spotify through the same unofficial, reverse-engineered interfaces as librespot, and some features use endpoints that Spotify does not document and may change or block at any time. Using a third-party client can conflict with Spotify's terms of service, so you use Openify at your own risk. It does not download or save music, and it only plays on Premium accounts.
