A native Spotify client, written in Rust.

Openify plays your Spotify Premium account through librespot and draws every pixel with gpui. No web view, no Electron, about 70 MB of memory.

Everything you play, nothing in the way.

Home, Explore, Library, artists and albums, with the cover of the current song as the only colour in the room.

Search that knows your library

One palette for songs, artists, albums and playlists from your library and Spotify, plus a few commands when you type their name.

CtrlK

Library tools

Find duplicates and other versions of one song, merge or split playlists, sort one for good, back up to JSON and see your own statistics. Edits can be undone.

Synced lyrics

In the side panel or full screen, with an optional translation under each line.

Equalizer with headphone profiles

Ten bands, presets, a preamp and correction curves from the open OPRA database.

Gapless and crossfade

Albums play without gaps. Optional crossfade from 2 to 12 seconds and three levels of volume normalization.

Queue rules

One version of each song, skip explicit songs, never play a chosen artist, or start a radio from anything.

Dark, Light or System

A dark room, a warm light palette, or follow Windows app mode as it changes.

Spotify Connect

Shows up as a device in the Spotify app on your phone. Rename it or turn it off in Settings.

Updates with a safety net

Updates install in the background. If a new version fails to start twice, Openify goes back to the previous one.

English and Turkish

The whole interface in both languages, plus media keys, the tray and the Windows media overlay.

Checked on every change

  • Tested on every PREach pull request is built and tested on Windows.
  • ARM64 tooThe ARM64 build compiles in CI next to x64.
  • rustfmt and ClippyFormatting and lints run on every change.
  • cargo-denyChecks licenses, banned crates and security advisories.
  • SHA-256 checksumsEvery release ships with checksums you can verify.
  • Design rules as testsType scale, spacing and contrast are checked by tests.

Your data stays on your PC No Openify server, no analytics, no telemetry.

Stored locally
Cache, history and statistics in your user folder; the Spotify session in the Windows Credential Manager.
Plays are not reported
Songs you play may not appear in Spotify's Recently played, your Wrapped or artists' play counts.
Few outside calls
Besides Spotify: LRCLIB for lyrics, Deezer for similar artists, OPRA for headphones and the update server.
Private session
One switch in the profile menu stops recording recent plays and statistics for that session.

PowerShell

Build from source

Needs Windows 10 or 11, Rust (rustup picks the pinned toolchain), the MSVC build tools and Git. No API key or .env file.

PowerShell
> git clone https://github.com/FurkanKY/Openify.git
> cd Openify
> cargo build --release
> .\target\release\openify.exe

The first build compiles gpui and takes a while. Run the tests with cargo test --release.

Requirements

  • Windows 10 or 11, x64 or ARM64
  • A Spotify Premium account; free accounts cannot stream through third-party clients
  • A working audio output

Good to know

  • Openify is early (0.1). Friend activity and artist following are experimental.
  • Screen readers are not supported yet: gpui has no Windows accessibility support. Keyboard use is well covered.
  • Windows only, no macOS or Linux builds.

Checksums for every file are in SHA256SUMS.txt on the release page.
